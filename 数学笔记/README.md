## 关于 OCR 原始文件

`OCR原始文件/` 里保留的是 MinerU 的**未经修改的识别结果**，用于对照。
其中有大量错误，典型如：

- 第 1 页 `(x-2)(x^4)` 实为 `(x-2)(x-3)`，`=2` 实为 `=3`
- 第 2 页 `\frac{\sin 2x}{2x}-2` 实为 `\frac{\sin 2x}{2x}\cdot 2`
- 第 6 页 `a+b\ge 2ab` 实为 `a^2+b^2\ge 2ab`

这些文件里的公式**不保证能正常渲染**（含 `\textcircled` 等非法命令），请以修正稿为准。
完整差异见 [`勘误对照表.md`](勘误对照表.md)。

## 说明

- 笔记中的公式使用 LaTeX（`$...$` / `$$...$$`），GitHub 可直接渲染。
- 保留了原笔记的思路标记与旁注（如“抓大头”“加减慎用”“画图更快呀”），
  并用引用块与正文区分：正文是知识点，引用块是笔记心得/易错提醒。
- 少数原笔记本身存疑之处已在文中标注说明。
